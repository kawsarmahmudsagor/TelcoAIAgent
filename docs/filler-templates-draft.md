# Bangla filler templates: shape-variation draft (for review)

Edit the lines in place: change the wording, delete lines, add your own. Keep the
`[A]`/`[W]`/`[T]`/`[S]` tag at the start of each line, or leave it out and the code
will work it out from the line. After review, the code takes the lines from this
file as they stand.

## Shapes

| Tag | Shape | Ends on | Example |
|---|---|---|---|
| A | opener, object + action | the action (বলছি / জানাচ্ছি) | জি, ব্যালেন্সটা চেক করে বলছি। |
| W | object + action, wait | a polite wait | ব্যালেন্সটা দেখে বলছি, এক মিনিট। |
| T | acknowledgement. object + action | the action, after a pause | বুঝতে পেরেছি। ব্যালেন্সটা দেখে জানাচ্ছি। |
| S | a wait or acknowledgement only | the wait | জি, আমাকে একটু সময় দিন। |

The code reads the shape from the line itself:
- **T:** a `।` in the middle of the line.
- **W:** the line ends on a wait word (এক মিনিট, এক সেকেন্ড, একটু সময় দিন, অপেক্ষা করুন).
- **S:** the line has no action verb.
- **A:** anything else.

Like the opening and the action today, the shape is not repeated in back-to-back lines.

New closings used here: **এখনই বলছি**, **জানিয়ে দিচ্ছি**, **আপডেট দিচ্ছি**, **দেখাচ্ছি**
(packages only, because a card follows).

Lines marked **(was: …)** are changed. Lines without it are kept as they are.

## Echo families (`_ECHO_BN`)

with a different first word; the tests check this.

## Notes for review

- **Word limit:** a line is at most 12 words. W and T lines are 2–3 words longer, so with a
  long `{x}` ("সাত দিনের তিন জিবির ডাটা প্যাকেজগুলো", 6 words) some come close. The code
  skips a line that goes over and picks another, so nothing breaks, but those shapes show up
  less often for long requests.
- **"সরি, অসুবিধার জন্য।"** is only in complaint and failed-recharge lines, where something went wrong.
- **"দেখাচ্ছি"** is only in package lines, because a card follows.
- **English lines** are unchanged in this draft. Say if you want the same treatment.
