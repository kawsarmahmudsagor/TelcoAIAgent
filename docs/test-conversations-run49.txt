TELCO BOT — REAL-LIFE CONVERSATION TESTS (built from logs/run_49.log)
=====================================================================

How to use
----------
- Log in as a customer with usage history, transactions and at least one failed
  recharge (run_49 used Samiha). Speak each line by voice; read the ★ lines aloud
  with the hesitations as written ("আম", "আ-আমি") — they are part of the test.
- One scenario = one call. Don't hang up between turns inside a scenario.
- After each turn, check "Expect" and the run log (logs/run_N.log): Tool / Router
  lines show what the bot looked up.
- Mark each turn: PASS / PARTIAL / FAIL, and copy the bot's reply on PARTIAL/FAIL.

Things to check on every turn
- Modern spoken Bangla, polite (আপনি), no bookish words; "প্যাকেজ" never "প্যাক";
  "বুঝতে পেরেছি" not "বুঝতে পারছি"; brand written "telco".
- No made-up numbers: every balance, price, date and count comes from a tool.
- Package answers show package cards on screen (also follow-ups and "আর কি আছে").
- The filler line ("দেখছি", "চেক করছি") fits the question and states no facts.

    Expect: the code is accepted when said alone (no "কোডটি হলো" needed).

    Expect: honest that it is the virtual assistant; request_human_agent with a
    case ref and follow-up promise; no fake transfer.
