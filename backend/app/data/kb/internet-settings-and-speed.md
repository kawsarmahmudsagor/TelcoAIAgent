# Internet settings and slow internet

## English

Settings: telco internet works automatically on most phones. If it does not, set the access point name (APN) by hand: open your phone's mobile network settings, choose Access Point Names, add a new APN named telco with the APN value telco.internet, leave the other fields empty, save it and select it. Then turn mobile data off and on again.

4G: to use 4G you need a 4G phone, a 4G SIM and 4G coverage where you are. In the phone's mobile network settings, set the preferred network type to 4G/LTE (or "auto"). SIMs older than about 2018 may be 3G only; a free SIM replacement at any customer care centre gives you a 4G SIM with the same number.

If the internet is slow or not working, check these in order:
1. Data left: ask the assistant how much data is left and when your package expires. When a package runs out, internet stops or is charged from your main balance.
2. Restart: turn airplane mode on for 10 seconds and off again, or restart the phone.
3. Mobile data and APN: make sure mobile data is on, the telco SIM is chosen for data on a dual-SIM phone, and the APN is telco.internet.
4. Network in your area: ask the assistant to check the network status for your area. If there is a known network problem, it tells you when it is expected to be fixed.
5. Indoors and crowds: thick walls, basements and very crowded places can lower the speed. Moving near a window or outside usually helps.

Still slow: if none of these help and there is no known problem in your area, the assistant opens a support case for our network team, and you are updated by SMS.

## বাংলা

সেটিংস: বেশিরভাগ ফোনে telco ইন্টারনেট নিজে থেকেই চালু হয়। না হলে এপিএন (অ্যাক্সেস পয়েন্ট নেম) নিজে সেট করুন: ফোনের মোবাইল নেটওয়ার্ক সেটিংসে গিয়ে Access Point Names খুলুন, telco নামে একটা নতুন এপিএন যোগ করুন, এপিএন-এর ঘরে telco.internet লিখুন, বাকি ঘর খালি রাখুন, সেভ করে সেটা সিলেক্ট করুন। তারপর মোবাইল ডাটা একবার বন্ধ করে আবার চালু করুন।

ফোরজি: ফোরজি চালাতে ফোরজি ফোন, ফোরজি সিম আর আপনার এলাকায় ফোরজি কাভারেজ লাগবে। ফোনের মোবাইল নেটওয়ার্ক সেটিংসে প্রেফার্ড নেটওয়ার্ক টাইপ 4G/LTE (বা অটো) করে দিন। ২০১৮-এর আগের কিছু সিম শুধু থ্রিজি হতে পারে; যেকোনো কাস্টমার কেয়ার সেন্টারে ফ্রিতে সিম বদলে একই নম্বরে ফোরজি সিম নিতে পারবেন।

ইন্টারনেট স্লো বা কাজ না করলে, এই ক্রমে দেখুন:
১. ডাটা বাকি আছে কি না: অ্যাসিস্ট্যান্টকে জিজ্ঞেস করুন কত ডাটা বাকি আর প্যাকেজের মেয়াদ কবে শেষ। প্যাকেজ শেষ হলে ইন্টারনেট বন্ধ হয়ে যায়, বা মেইন ব্যালেন্স থেকে টাকা কাটে।
২. রিস্টার্ট: ১০ সেকেন্ডের জন্য এয়ারপ্লেন মোড চালু করে আবার বন্ধ করুন, বা ফোন রিস্টার্ট দিন।
৩. মোবাইল ডাটা আর এপিএন: মোবাইল ডাটা চালু আছে কি না, ডুয়াল সিম ফোনে ডাটার জন্য telco সিম সিলেক্ট করা আছে কি না, আর এপিএন telco.internet আছে কি না দেখুন।
৪. আপনার এলাকার নেটওয়ার্ক: অ্যাসিস্ট্যান্টকে আপনার এলাকার নেটওয়ার্ক স্ট্যাটাস দেখতে বলুন। জানা কোনো নেটওয়ার্ক সমস্যা থাকলে কবে ঠিক হবে, সেটাও জানিয়ে দেবে।
৫. ঘরের ভেতর আর ভিড়: মোটা দেয়াল, বেসমেন্ট বা খুব ভিড়ের জায়গায় স্পিড কমে যেতে পারে। জানালার কাছে বা বাইরে গেলে সাধারণত ভালো হয়।

তারপরও স্লো: এগুলোতে কাজ না হলে আর আপনার এলাকায় জানা কোনো সমস্যা না থাকলে, অ্যাসিস্ট্যান্ট আমাদের নেটওয়ার্ক টিমের জন্য একটা সাপোর্ট কেস খুলে দেবে, আর আপডেট এসএমএসে জানানো হবে।
