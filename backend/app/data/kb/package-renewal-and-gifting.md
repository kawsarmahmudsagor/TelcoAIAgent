# Package renewal, stopping a package and buying for someone else

## English

Renewal: most telco packages do not renew by themselves. When such a package expires, its leftover data, minutes and SMS are gone, and you buy a new one when you need it. Some packages are auto-renewable: the package details and its card say "Auto-renews". When you buy one of these, auto-renew is on and your account shows "auto-renew on"; it renews at expiry from your main balance if it has enough, and you are told by SMS before each renewal. Whether a given package auto-renews is in its package details, not in this document. To turn auto-renew off, call the hotline 121.

Before expiry: the assistant tells you when a package expires today and can suggest a new one. You can buy the same package again before the old one ends; the new one is added as a separate package with its own validity, and the one that expires first is used first.

Stopping a package: an activated package cannot be stopped, cancelled or refunded, even if you have not used it. Check the package and its price before you confirm with the code. If a package was charged but never started, report it and the assistant opens a support case.

Buying for someone else: a package can only be bought for the number it will be used on. To help someone else, recharge their number (any telco number, from 20 taka) and they can buy the package they want from their main balance. The reward points for that recharge go to you.

Changing to a different package: you cannot switch an active package for another one. Buy the new package; both work side by side until each one expires.

## বাংলা

রিনিউ: telco-এর বেশিরভাগ প্যাকেজ নিজে থেকে রিনিউ হয় না। মেয়াদ শেষ হলে বাকি ডাটা, মিনিট আর এসএমএস চলে যায়, আর দরকার হলে আবার নতুন প্যাকেজ নিতে হয়। কিছু প্যাকেজ অটো-রিনিউ হয়: প্যাকেজের তথ্যে আর কার্ডে "Auto-renews" লেখা থাকে। এগুলো কিনলে অটো-রিনিউ চালু থাকে আর অ্যাকাউন্টে "অটো-রিনিউ চালু" দেখায়; মেইন ব্যালেন্সে যথেষ্ট টাকা থাকলে মেয়াদ শেষে এগুলো সেখান থেকে রিনিউ হয়, আর প্রতিবার রিনিউর আগে এসএমএসে জানানো হয়। অটো-রিনিউ বন্ধ করতে হটলাইন ১২১-এ কল করুন।

মেয়াদ শেষের আগে: কোনো প্যাকেজের মেয়াদ আজকেই শেষ হলে অ্যাসিস্ট্যান্ট জানিয়ে দেয়, আর নতুন প্যাকেজ সাজেস্ট করতে পারে। পুরনোটা শেষ হওয়ার আগেই একই প্যাকেজ আবার কিনতে পারেন; নতুনটা নিজের মেয়াদ নিয়ে আলাদা প্যাকেজ হিসেবে যোগ হয়, আর যেটার মেয়াদ আগে শেষ সেটা আগে খরচ হয়।

প্যাকেজ বন্ধ করা: চালু হয়ে যাওয়া প্যাকেজ বন্ধ, বাতিল বা ফেরত করা যায় না, ব্যবহার না করলেও না। কোড দিয়ে কনফার্ম করার আগে প্যাকেজ আর দামটা দেখে নিন। টাকা কেটেছে কিন্তু প্যাকেজ চালু হয়নি, এমন হলে জানান, অ্যাসিস্ট্যান্ট একটা সাপোর্ট কেস খুলে দেবে।

অন্য কারও জন্য কেনা: প্যাকেজ শুধু যে নম্বরে ব্যবহার হবে, সেই নম্বরের জন্যই কেনা যায়। অন্য কাউকে দিতে চাইলে তার নম্বরে রিচার্জ করে দিন (যেকোনো telco নম্বরে, ২০ টাকা থেকে), তারপর তিনি নিজের মেইন ব্যালেন্স থেকে পছন্দের প্যাকেজটা কিনে নিতে পারবেন। ওই রিচার্জের রিওয়ার্ড পয়েন্ট পাবেন আপনি।

অন্য প্যাকেজে বদলানো: চালু প্যাকেজ বদলে অন্য প্যাকেজ নেওয়া যায় না। নতুন প্যাকেজটা কিনে নিন; দুটোই নিজের নিজের মেয়াদ পর্যন্ত একসাথে চলবে।
